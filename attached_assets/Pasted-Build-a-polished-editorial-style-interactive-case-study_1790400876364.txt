Build a polished, editorial-style interactive case study for my portfolio about a conversational shopping agent I led at The RealReal.

The goal is NOT to make a traditional product case study with lots of text, cards, and bullet points.

The goal is to **visually tell the story of why conversational shopping matters**.

The core idea:

The RealReal has millions of unique secondhand products. Traditional keyword search works when shoppers know exactly what they want AND know how the catalog describes it. But shoppers don't naturally think in catalog attributes.

They think:

“Something for a summer wedding in Napa.”

“90s minimalist black dress for a black-tie wedding.”

“I want something like this, but less formal.”

“Which of these would work with these shoes?”

An LLM can understand that nuance.

The agent turns search from a keyword-matching exercise into a conversation: users can search naturally with text or images, refine what they want through dialogue, compare products, and get styling/outfitting guidance.

The portfolio story should communicate:

**6M+ products → discovery is hard → keywords force users to speak the catalog's language → LLMs understand intent → conversational shopping makes the inventory easier to explore.**

Use the uploaded TRR Conversational Shopping deck as source material and preserve the terminology and product concepts from it. In particular, the deck describes the shift from precise keywords toward images, half-baked ideas, occasions and trends; guided discovery; product comparison; and styling/outfitting recommendations.

#### 4. LET THE USER EXPERIENCE IT

This should be the centerpiece of the case study.

Create an interactive simulated shopping-agent experience.

Start with:

**“Dresses for a summer wedding in Napa”**

Each card should feel like a real TRR product card.

Then let the user type:

**“Less formal. Something I could wear with sandals.”**

Results update.

Then:

**“Which one is easiest to dress up later?”**

The agent compares 2–3 products.

Then:

**“What would you wear with it?”**

The agent generates an outfitting recommendation.

The interaction should demonstrate the product better than paragraphs explaining it.

The deck's intended discovery journey is: input → search → results/refinement, followed by comparison and decision.

But the name “AskTRR” led users to interpret it as a **customer-service assistant**.

Visualize the mismatch:

🔎 Discovery
Compare

**AI products are not just model experiences.
The product has to teach users what it is.**

### DESIGN DIRECTION

Think **Brian Chesky / modern product portfolio / editorial fashion magazine**, not SaaS dashboard.

The RealReal is a fashion marketplace, so the case study should feel like fashion + technology.

Use:

* huge typography
* lots of whitespace
* beautiful product imagery
* editorial layouts
* subtle motion
* oversized numbers
* product cards
* conversational UI
* occasional full-bleed visual moments
* restrained neutral palette
* TRR-inspired luxury aesthetic

Avoid:

* generic AI gradients
* robot imagery
* glowing blue/purple AI effects
* excessive rounded cards
* dashboard-style layouts
* giant paragraphs
* generic “AI-powered” language
* stock illustrations
* cheesy neural-network graphics

The **products should be the visual hero**.

The interface should feel like an actual shopping experience, not a presentation about one.
