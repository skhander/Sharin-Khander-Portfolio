Restructure the existing Curation Tool portfolio page into a **spoken-story / interview memory-bullet format**.

The page is NOT meant to be a case study that someone reads linearly. It is a visual aid for me during an interview. I need to be able to glance at the page, see a few words, and immediately remember the next part of my spoken story.

### Core principle

Turn the current page into **8 clear story beats**:

1. THE PROBLEM
2. THE SHIFT
3. WHAT I BUILT
4. WHAT I OWNED
5. THE GOALS
6. THE HARD PART
7. THE RESULT
8. WHAT'S NEXT

Each section should contain:

* A very short, bold headline that acts as a memory trigger
* 1–3 short supporting bullets
* Important numbers displayed visually
* Lots of whitespace
* No paragraphs
* No dense blocks of text

The page should feel like an **executive presentation / interview cheat sheet**, not a traditional product case study.

## 1. THE PROBLEM

Large headline:

**WEEKS OF WORK. DAYS LIVE.**

Supporting bullets:

* Merchandisers spent weeks building assortments that might only live for a few days.
* Switching between multiple tools.
* Manually searching through **6M products**.
* No recommendations to help decide what to pull.

Visual emphasis:

**6M products**
**weeks → days**

The phrase "weeks of work, days live" should be one of the strongest visual moments on the page.
