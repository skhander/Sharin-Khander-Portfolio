name: Virtual Try-On page intent
description: Why a recording is retained even though it is not shown in the homepage card.
---

Keep the Product Detail recording available for a future separate Virtual Try-On landing page. The homepage project card should show only the Browse Grid recording unless the user changes that direction.

**Why:** The user explicitly chose to place Product Detail on a separate linked page later, rather than on the current portfolio landing page. Removing it from the card does not mean the source file is disposable.

**How to apply:** When creating the future page, reuse the preserved recording and add the link only when requested. Do not add the recording back to the homepage card by default.
