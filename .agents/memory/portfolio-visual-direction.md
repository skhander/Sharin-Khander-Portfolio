---
name: Portfolio visual direction
description: Endorsed visual direction and employer-facing constraints for this portfolio.
---

The portfolio owner explicitly liked the hypergoo, Gen-Z streetwear concept and felt the earlier quiet editorial treatment was too mild. This endorses an exploration direction, not a replacement of the live site.

**Why:** Employers need to recognize the person's name and see evidence of work quickly. The owner called out that their name is already hard for others to pronounce, so visual distortion must not make it harder to read.

**How to apply:** Keep the expressive liquid shapes, saturated campaign energy, and glitch accents away from the core name and project copy. Put project evidence within the first screen when practical. Do not transfer a canvas concept to the live portfolio without explicit approval.
