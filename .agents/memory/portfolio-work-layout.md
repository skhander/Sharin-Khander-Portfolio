---
name: Portfolio work layout
description: The preferred layout for the portfolio homepage's selected-work section.
---

Keep the portfolio homepage's selected-work presentation as a single-column vertical list rather than a multi-column card grid, unless the user asks otherwise.

**Why:** After reviewing an image-led grid, the user explicitly said the earlier vertical list was cleaner.

**How to apply:** Preserve each project's compact visual, badges, and description within its row when refining this portfolio. This is a project-specific preference, not a general preference for unrelated apps.
