Keep the selected minimal homepage as the baseline; explore image-centric layouts in separate frames rather than replacing it. Prefer a vertical project sequence over a conventional multi-column card grid unless the user asks otherwise.

**Why:** After reviewing an image-led grid, the user said the vertical list was cleaner. They also rejected a separate mobile-first image-led homepage but asked to explore ways to make only the project section more image-centric while leaving the selected minimal frame as-is.

**How to apply:** Preserve project identities, authentic imagery, badges, descriptions, and filters in explorations. Do not infer approval of a new variant or apply it to the live portfolio. This is project-specific, not a general preference for unrelated apps.
