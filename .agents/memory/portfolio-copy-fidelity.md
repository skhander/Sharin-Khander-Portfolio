---
name: Portfolio copy fidelity
description: Copy preservation rule for visual changes to the portfolio.
---

For typography, spacing, and other visual-only refinements, retain existing visible wording exactly. Never add an eyebrow, caption, category, badge, or filler label to occupy whitespace.

**Why:** The user explicitly prefers empty space over invented descriptive text and has asked that even capitalization and punctuation stay exact during visual-only work.

**How to apply:** Inspect current rendered copy before editing. Change copy only when the user explicitly supplies the replacement string; otherwise make the design work with the existing text.
